# Error Detection using Parity Checker in Verilog

This project implements an Even Parity Generator and Parity Checker using Verilog HDL to detect errors during digital data transmission.

## Features
- Generates parity bit using XOR logic
- Detects transmission errors
- Includes multiple test cases
- Simulated using waveform analysis

## Concepts Used
- Verilog HDL
- XOR Gate
- Parity Bit
- Error Detection
- Digital Logic Design
- Testbench Simulation

## Files
- parity_checker_system.v
- testbench.v

## Output
- Error = 0 → No Error
- Error = 1 → Error Detected
